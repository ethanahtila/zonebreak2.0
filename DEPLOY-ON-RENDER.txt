ZONEBREAK 1.6.8 — Three-fighter Duel

1. Extract this ZIP, then open the ZONEBREAK folder.
2. On GitHub choose Add file > Upload files.
3. Drag ALL the CONTENTS of ZONEBREAK onto that page TOGETHER, including the
   test folder and vendor folder. Do not upload the ZIP. Do not move the files
   from inside vendor/ws to the top level. Commit the upload.
4. At GitHub's top level, package.json, package-lock.json, server.cjs, index.html,
   test/ and vendor/ should be visible together.
5. Render: use a Node Web Service and these exact settings:
   Root Directory: LEAVE BLANK (do not type these words)
   Build Command: npm ci --omit=dev
   Start Command: npm start
   Health Check Path: /health
   Environment variable: NODE_VERSION = 24
6. Save and choose Manual Deploy > Clear build cache & deploy.

If you upload the enclosing ZONEBREAK folder itself, rather than its contents,
Root Directory must instead be ZONEBREAK (case-sensitive).

The game's package.json is named zonebreak internally. vendor/ws/package.json
is named ws. Both are intentional, separate files in different folders.
Replace BOTH root package files in the same commit. Mixing the nested ws
package.json with the root package-lock.json causes the EUSAGE dependency error.

Folder guide:
  test/       optional automated checks; not needed to run the live game
  vendor/ws/  required bundled multiplayer library; preserve its lib subfolder
  .node-version  Node version hint; may be hidden on your computer

If .node-version does not upload, setting NODE_VERSION=24 in Render handles it.
There is no folder named version in the package. Do not flatten vendor/ws/lib.

This package includes the updated 1.6.8 gameplay and generated PLAY.html.

ZONEBREAK MODE (unlocks at 750 trophy-road trophies)
3v3. Hold the relay. First to 150 points, or the lead at three minutes, wins.
Hold B at a console (75 Break energy). Hold V to preview the terrain change.
Changes warn for 2 seconds, stay for 20, then warn for 2 before resetting safely.
Architects interact faster and from farther away. All fighters can activate.
Includes solo bots, friends rooms, matchmaking and ranked rotation.
Existing 2,000 fighters and saved profiles are preserved.

1.6.8 LOOTBOX REWARDS
Mythic: 5% gadget/passive combined. Legendary: 8% combined plus 2% hypercharge.
All level-eligible gadgets/passives on owned fighters share one equal-chance pool.
Owned abilities stay in the pool; a duplicate gives 1,000 coins with no reroll.
Random owned-fighter hypercharge at any level; duplicates give 2,500 coins.
Early hypercharges stay saved and become usable at level 20.

1.6.8 MUTATION MADNESS
Unlock: 900 Trophy Road trophies plus five owned fighters. Duel and 3v3.
Five wheel spins: speed, damage, health, super, attack. No repeated donor.
Keep the build for the whole match. Knockout rounds, first team to FIVE wins.
Equipped extras disabled only in this mode; Pilot/Summoner utility controls stay.
Render settings remain unchanged.
